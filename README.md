# AnoTalks

## Het Project

### De Probleemstelling

De eerste stap zetten naar psychologische hulp is vaak moeilijk. Er zit een hoge drempel aan verbonden voor velen. Dit kan zijn omdat je je niet snel op je gemak voelt bij een persoon die je niet kent of waarvan je denkt: "Die doet zijn/haar job ook maar gewoon".\
Een andere reden kan ook zijn dat je niet goed aan jezelf kan toegeven dat je het wil of nodig hebt. Als er iets in je zegt dat je het misschien moet doen, doe het. Het kan nooit kwaad om eens een gesprek te hebben met een psycholoog.

Naar de psycholoog gaan is een sterkte, geen teken van zwakte.

### Het Idee

AnoTalks wordt een platform waar je volledig anoniem een eerste gesprek kan hebben met een psycholoog. Wanneer je de site bezoekt, krijg een willekeurige anonieme naam. Je kan dan aanduiden wat je het meest in de weg ligt en een gesprek beginnen met een officieel geregistreerde psycholoog / psychologe. Alles wat er in dat gesprek gezegd wordt, is tussen jou en de hulpverlenende.
